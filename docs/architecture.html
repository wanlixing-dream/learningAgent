★ Technical Highlights

🔀 三层 Agent 解耦

接口层 / 协调层 / 功能层清晰分离。MainAgent 统一路由，各功能 Agent 独立演化，新增 Agent 零侵入。

🔍 双通道混合检索

RAG Pipeline 同时走 Vector (bge-m3) + BM25 (rank_bm25)，分数融合后注入 LLM。稀疏/稠密互补，召回率显著优于单通道。

🧠 5 信号记忆检索

MemoryRetriever 融合 semantic / keyword / entity / importance / recency 五个信号，自动降级（无 Embedder 时 fallback TF-IDF）。

📈 概念级自适应学习

MasteryTracker 按概念粒度追踪掌握度，答题自动更新。间隔复习调度（答对 +3 天 / 答错 +1 天），薄弱概念优先出题。

📊 确定性 Agent 评估

AgentEvaluator 5 维度加权评分，无需 LLM 即可量化 Agent 执行质量。配合 TraceRecorder 全链路追踪，可观测性开箱即用。

🔌 MCP 标准化接口

7 Tools + Resources + 4 Prompts，通过 FastMCP 暴露为标准 MCP Server。任何 MCP 客户端（Claude Desktop、Cursor 等）即插即用。

💾 零依赖本地存储

Markdown + JSON + JSONL + ChromaDB，全部本地持久化，无需外部数据库。MemoryStore append-only + 领域分片，查询 O(n) 但足够实用。

🌐 全栈可视化

React + Vite + TailwindCSS + Recharts 前端，FastAPI REST 后端。雷达图 / 柱状图 / 进度条可视化掌握度，聊天界面支持互动学习。
