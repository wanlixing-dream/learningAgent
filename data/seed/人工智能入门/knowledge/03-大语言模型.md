# 大语言模型（LLM）

## 一句话解释

大语言模型就是**读了互联网上几乎所有文字后，学会了"接话"的 AI**。

## ChatGPT 是怎么工作的

你以为 ChatGPT 在"思考"。实际上它在做一件很简单（但规模巨大）的事：

**预测下一个最可能的词。**

```
你输入：今天天气真
AI 预测：好  （因为"今天天气真好"在训练数据中出现得最多）
```

它不断预测下一个词，连起来就成了一段话：

```
今天 → 天气 → 真 → 好 → ， → 适合 → 出去 → 散步 → 。
```

## 大语言模型有多"大"

| 模型 | 参数量 | 训练数据 |
|------|--------|---------|
| GPT-3 | 1750 亿 | 5000 亿词 |
| GPT-4 | 未公开（估计万亿级） | 更多 |
| LLaMA 2 | 70 亿~700 亿 | 2 万亿词 |

"参数"可以理解为模型"记住"的知识点数量。参数越多，模型越"聪明"。

## LLM 能做什么

| 能力 | 例子 |
|------|------|
| 对话 | ChatGPT、文心一言 |
| 写代码 | GitHub Copilot |
| 翻译 | 多语言翻译 |
| 摘要 | 把长文章压缩成一段话 |
| 创作 | 写诗、写故事、写邮件 |
| 推理 | 数学题、逻辑题 |

## LLM 不能做什么

| 限制 | 原因 |
|------|------|
| ❌ 保证正确 | 它在"猜"最可能的答案，不是在"计算" |
| ❌ 联网搜索 | 基础模型只知道训练数据里的内容 |
| ❌ 记住你 | 每次对话默认是独立的 |
| ❌ 真正理解 | 它在模式匹配，不是在"思考" |

这就是为什么 AI 有时会"一本正经地胡说八道"——这个现象叫**幻觉（Hallucination）**。

## Prompt 的重要性

Prompt = 你给 AI 的输入（提示词）。同样的问题，不同的问法，答案质量差很多：

### ❌ 差的 Prompt
```
写一首诗
```

### ✅ 好的 Prompt
```
请用五言绝句的格式，写一首关于春天桃花的古诗。
要求：意境优美，有色彩描写。
```

### Prompt 技巧

1. **角色设定**：`你是一个资深的 Python 教师`
2. **明确要求**：`用列表形式，每条不超过 20 字`
3. **给出例子**：`参考这个格式：...`
4. **分步骤**：`第一步…第二步…第三步…`

## 小测验

1. 大语言模型的核心工作原理是？
   - A. 搜索互联网
   - B. 预测下一个最可能的词
   - C. 查数据库
   - **答案：B**

2. AI 有时会编造不存在的事实，这叫什么？
   - A. Bug
   - B. 幻觉（Hallucination）
   - C. 过拟合
   - **答案：B**
