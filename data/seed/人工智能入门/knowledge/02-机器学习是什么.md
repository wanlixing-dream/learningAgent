# 机器学习是什么

## 一句话解释

机器学习就是**让计算机从数据中自己找规律**，而不是人工写规则告诉它。

## 传统编程 vs 机器学习

### 传统编程

```
人类写规则 + 数据 → 计算机 → 结果
```

例子：判断邮件是否是垃圾邮件
```python
# 人工写规则
if "免费" in email and "中奖" in email:
    return "垃圾邮件"
```

问题：垃圾邮件花样太多，规则写不完。

### 机器学习

```
大量数据 + 正确答案 → 计算机自己学规则 → 模型 → 预测新数据
```

例子：
```
给计算机看 10000 封邮件（标注好哪些是垃圾邮件）
    ↓
计算机自己总结出规律
    ↓
以后新邮件来了，自动判断
```

## 机器学习的三种方式

### 1. 监督学习 — 有老师教

给计算机"题目"和"标准答案"，让它学会举一反三。

| 数据（题目） | 标签（答案） |
|-------------|-------------|
| 一张猫的照片 | "猫" |
| 一张狗的照片 | "狗" |
| 一封正常邮件 | "正常" |
| 一封垃圾邮件 | "垃圾" |

常见应用：图片分类、垃圾邮件过滤、房价预测

### 2. 无监督学习 — 自己摸索

只给数据，不给答案，让计算机自己发现规律。

例子：
- 给电商 100 万用户的购买数据
- 计算机自动把用户分成几组（"经常买电子产品的"、"喜欢买衣服的"）
- 你没告诉它怎么分，它自己找到了规律

常见应用：用户分群、异常检测

### 3. 强化学习 — 试错学习

像训练小狗一样：做对了给奖励，做错了不给。

例子：
- AI 下棋：赢了得 +1 分，输了得 -1 分
- 反复对局后，AI 学会了怎么下棋更容易赢

常见应用：游戏 AI、机器人控制、自动驾驶

## 什么是"模型"

模型就是机器学习的"成果"——计算机从数据中学到的**规律的总结**。

类比：
- 数据 = 大量的考试题和答案
- 训练 = 学生做题、总结规律
- 模型 = 学生脑子里的"解题技巧"
- 预测 = 用解题技巧做新的题

## 机器学习的流程

```
收集数据 → 清洗数据 → 选择算法 → 训练模型 → 评估效果 → 部署使用
```

1. **收集数据**：越多越好，质量越高越好
2. **清洗数据**：去掉错误的、缺失的数据
3. **选择算法**：决策树？神经网络？看任务选
4. **训练模型**：让算法在数据上"学习"
5. **评估效果**：准确率够不够高？
6. **部署使用**：放到实际产品中

## 小测验

1. 机器学习和传统编程的最大区别是什么？
   - A. 机器学习不需要计算机
   - B. 机器学习从数据中自己学规律，不需要人工写规则
   - C. 传统编程更先进
   - **答案：B**

2. "给 AI 看 1000 张猫和狗的照片并标注好"属于哪种学习方式？
   - A. 监督学习
   - B. 无监督学习
   - C. 强化学习
   - **答案：A**
