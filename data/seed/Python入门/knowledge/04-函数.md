# 函数

## 一句话解释

函数就是把一段代码**打包起来**，起个名字，以后想用的时候直接**叫名字**就行。

## 为什么需要函数

不用函数（重复写同样的代码）：

```python
print("=" * 20)
print("欢迎使用系统")
print("=" * 20)

# ... 其他代码 ...

print("=" * 20)
print("欢迎使用系统")
print("=" * 20)
```

用函数（写一次，随处使用）：

```python
def show_welcome():
    print("=" * 20)
    print("欢迎使用系统")
    print("=" * 20)

show_welcome()  # 第一次调用
show_welcome()  # 第二次调用
```

## 定义和调用函数

```python
# 定义函数（教计算机一个新技能）
def greet():
    print("你好！")

# 调用函数（使用这个技能）
greet()  # 输出：你好！
```

## 带参数的函数

参数就像函数的"输入口"：

```python
def greet(name):
    print(f"你好，{name}！")

greet("小明")  # 你好，小明！
greet("小红")  # 你好，小红！
```

多个参数：

```python
def add(a, b):
    print(f"{a} + {b} = {a + b}")

add(3, 5)    # 3 + 5 = 8
add(10, 20)  # 10 + 20 = 30
```

## 返回值

函数可以"算出一个结果"交还给你：

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 8

# 可以直接用在表达式里
total = add(10, 20) + add(30, 40)
print(total)  # 100
```

## 默认参数

```python
def greet(name, language="中文"):
    if language == "中文":
        print(f"你好，{name}！")
    else:
        print(f"Hello, {name}!")

greet("小明")             # 你好，小明！（默认中文）
greet("Tom", "English")  # Hello, Tom!
```

## 实用例子

### 温度转换器

```python
def celsius_to_fahrenheit(c):
    """摄氏度转华氏度"""
    return c * 9 / 5 + 32

print(celsius_to_fahrenheit(0))    # 32.0
print(celsius_to_fahrenheit(100))  # 212.0
```

### 判断奇偶

```python
def is_even(number):
    """判断是否是偶数"""
    return number % 2 == 0

print(is_even(4))   # True
print(is_even(7))   # False
```
