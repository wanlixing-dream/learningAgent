# 列表和字典

## 列表 (list) — 有序的数据容器

列表就像一个**购物清单**，可以往里面放很多东西，而且有顺序。

### 创建列表

```python
fruits = ["苹果", "香蕉", "橘子"]
numbers = [1, 2, 3, 4, 5]
mixed = [1, "hello", True, 3.14]  # 可以混合类型
empty = []  # 空列表
```

### 访问元素（从 0 开始数）

```python
fruits = ["苹果", "香蕉", "橘子"]
print(fruits[0])   # "苹果"（第 1 个）
print(fruits[1])   # "香蕉"（第 2 个）
print(fruits[-1])  # "橘子"（最后 1 个）
```

### 常用操作

```python
fruits = ["苹果", "香蕉"]

# 添加元素
fruits.append("橘子")        # ["苹果", "香蕉", "橘子"]

# 删除元素
fruits.remove("香蕉")        # ["苹果", "橘子"]

# 列表长度
print(len(fruits))            # 2

# 检查是否包含
print("苹果" in fruits)      # True

# 排序
numbers = [3, 1, 4, 1, 5]
numbers.sort()                # [1, 1, 3, 4, 5]

# 遍历列表
for fruit in fruits:
    print(fruit)
```

### 列表切片

```python
nums = [0, 1, 2, 3, 4, 5]
print(nums[1:4])   # [1, 2, 3]（从索引 1 到 3）
print(nums[:3])    # [0, 1, 2]（前 3 个）
print(nums[3:])    # [3, 4, 5]（从索引 3 到最后）
```

## 字典 (dict) — 键值对容器

字典就像一本**真正的字典**——通过"词条"找到"解释"。

### 创建字典

```python
student = {
    "name": "小明",
    "age": 20,
    "grade": "大二"
}
```

`"name"` 是**键（key）**，`"小明"` 是**值（value）**。

### 访问和修改

```python
# 读取
print(student["name"])     # "小明"
print(student.get("age"))  # 20

# 修改
student["age"] = 21

# 添加新键值对
student["major"] = "计算机"

# 删除
del student["grade"]
```

### 遍历字典

```python
student = {"name": "小明", "age": 20}

# 遍历所有键
for key in student:
    print(key)              # "name", "age"

# 遍历所有值
for value in student.values():
    print(value)            # "小明", 20

# 遍历键值对
for key, value in student.items():
    print(f"{key}: {value}")
```

## 列表 vs 字典

| 特点 | 列表 | 字典 |
|------|------|------|
| 存取方式 | 按位置（索引） | 按名字（键） |
| 是否有序 | 有序 | Python 3.7+ 有序 |
| 适合场景 | 同类数据的集合 | 描述一个事物的多个属性 |
| 例子 | 一组成绩 `[90, 85, 95]` | 一个学生 `{"name": "...", "age": ...}` |
