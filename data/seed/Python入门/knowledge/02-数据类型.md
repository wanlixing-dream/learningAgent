# Python 数据类型详解

## 四种基本数据类型

### 1. 整数 (int) — 没有小数点的数

```python
age = 25
year = 2024
negative = -10

# 可以做数学运算
print(10 + 3)   # 13（加法）
print(10 - 3)   # 7（减法）
print(10 * 3)   # 30（乘法）
print(10 / 3)   # 3.333...（除法，注意结果是小数）
print(10 // 3)  # 3（整除，只取整数部分）
print(10 % 3)   # 1（取余数）
print(2 ** 10)  # 1024（幂运算，2 的 10 次方）
```

### 2. 浮点数 (float) — 带小数点的数

```python
pi = 3.14159
price = 9.99
temperature = -3.5

# 注意精度问题
print(0.1 + 0.2)  # 0.30000000000000004（不是 0.3！）
# 这是所有编程语言的通病，不用太担心
```

### 3. 字符串 (str) — 文字

```python
name = "小明"           # 双引号
greeting = '你好'       # 单引号（效果一样）
long_text = """
这是多行
文字内容
"""                      # 三引号（可以写多行）

# 字符串拼接
first = "你好"
second = "世界"
print(first + second)    # "你好世界"

# 格式化字符串（f-string，最常用）
name = "小明"
age = 20
print(f"{name}今年{age}岁")  # "小明今年20岁"

# 字符串长度
print(len("Hello"))  # 5
```

### 4. 布尔值 (bool) — 对或错

```python
is_student = True
is_rainy = False

# 比较运算的结果是布尔值
print(5 > 3)    # True
print(5 == 3)   # False
print(5 != 3)   # True
```

## 类型转换

有时需要把一种类型转成另一种：

```python
# 字符串 → 整数
age_str = "25"
age_num = int(age_str)     # 25

# 整数 → 字符串
num = 100
text = str(num)            # "100"

# 字符串 → 小数
price = float("9.99")     # 9.99

# 查看类型
print(type(42))            # <class 'int'>
print(type("hello"))       # <class 'str'>
print(type(3.14))          # <class 'float'>
print(type(True))          # <class 'bool'>
```

## input() — 获取用户输入

```python
name = input("你叫什么名字？")
print(f"你好，{name}！")

# 注意：input() 返回的永远是字符串
age = input("你几岁？")        # age 是字符串 "20"
age = int(input("你几岁？"))   # 转成整数才能做计算
```

## 小测验

1. `type(3.14)` 的结果是？
   - A. int
   - B. float
   - C. str
   - **答案：B**

2. `"3" + "5"` 的结果是？
   - A. 8
   - B. "8"
   - C. "35"
   - **答案：C**（字符串拼接，不是数学加法）
