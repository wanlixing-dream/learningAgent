# Python 入门 — 学习计划

> 适合人群：知道编程是什么，想学第一门语言的初学者

## 前置知识

建议先完成"编程启蒙"课程，了解变量、条件、循环等基本概念。

## 学习目标

掌握 Python 基础语法，能独立写出 50 行以内的小程序。

## 学习路径

### 第一阶段：环境搭建和第一行代码（第 1 天）

1. **安装 Python** — 下载、安装、验证
2. **Hello World** — 写出第一个 Python 程序
3. **Python 交互模式** — 把 Python 当计算器用

### 第二阶段：基础语法（第 1-2 周）

4. **数据类型详解** — 数字、字符串、布尔值
5. **字符串操作** — 拼接、切片、格式化
6. **列表和字典** — Python 最常用的数据容器
7. **条件和循环** — if/for/while 在 Python 中的写法

### 第三阶段：函数和模块（第 3 周）

8. **函数** — 定义函数、参数、返回值
9. **模块和导入** — 使用别人写好的代码
10. **文件操作** — 读写文本文件

### 第四阶段：实战项目（第 4 周）

11. **项目：猜数字游戏** — 综合运用所有知识
12. **项目：待办事项清单** — 列表 + 文件 + 循环
13. **下一步学什么** — Web / 数据分析 / AI 方向指引

## 评估方式

- 每节有代码练习题
- 能独立完成"猜数字游戏"即为达标
