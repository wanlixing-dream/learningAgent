# 变量和数据

## 一句话解释

变量就是给数据起个名字，方便以后用——就像**给盒子贴标签**。

## 生活类比

想象你有很多盒子：

- 📦 贴了"年龄"标签的盒子，里面放着数字 `20`
- 📦 贴了"名字"标签的盒子，里面放着文字 `"小明"`
- 📦 贴了"身高"标签的盒子，里面放着数字 `175.5`

在编程里：

```python
age = 20          # 整数
name = "小明"      # 文字（字符串）
height = 175.5    # 小数
```

`age`、`name`、`height` 就是**变量名**（标签），`20`、`"小明"`、`175.5` 就是**数据**（盒子里的东西）。

## 常见的数据类型

| 类型 | 说明 | 例子 |
|------|------|------|
| 整数 (int) | 没有小数点的数字 | `1`、`100`、`-5` |
| 小数 (float) | 有小数点的数字 | `3.14`、`175.5` |
| 字符串 (str) | 一段文字，用引号包起来 | `"你好"`、`"Hello"` |
| 布尔值 (bool) | 只有两个值：对或错 | `True`、`False` |

## 变量的规则

### 命名规则

```python
# ✅ 合法的变量名
my_name = "小明"
age2 = 20
_score = 95

# ❌ 不合法的变量名
2age = 20        # 不能以数字开头
my name = "小明"  # 不能有空格
```

### 变量可以改变

这就是为什么叫"变"量——里面的东西可以换：

```python
score = 60       # 刚开始考了 60 分
score = 90       # 复习后考了 90 分
# 现在 score 的值是 90，60 被替换了
```

## 用变量做计算

```python
price = 10       # 单价 10 元
count = 3        # 买 3 个
total = price * count  # total = 30

print(total)     # 屏幕显示：30
```

## 为什么需要变量

不用变量：
```python
print(10 * 3)    # 30，但看不出在算什么
```

用变量：
```python
price = 10
count = 3
total = price * count
print(total)     # 30，一目了然：单价 × 数量 = 总价
```

变量让代码**可读、可改、可复用**。
