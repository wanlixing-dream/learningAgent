# 编程语言是什么

## 一句话解释

编程语言是人类和计算机之间的**翻译工具**——你用它写指令，计算机能理解并执行。

## 为什么需要编程语言

计算机只懂 0 和 1（二进制），但人类写 01001001 会疯掉。

编程语言就是**中间的桥梁**：

```
人类的想法
    ↓  （用编程语言写下来）
源代码（人能看懂的文本）
    ↓  （编译器/解释器翻译）
机器码（0 和 1）
    ↓
计算机执行
```

## 编程语言长什么样

### Python（最适合初学者）
```python
print("你好，世界！")
```

### JavaScript（做网页用的）
```javascript
console.log("你好，世界！");
```

### Java（做手机 App 常用）
```java
System.out.println("你好，世界！");
```

### C 语言（最接近计算机底层）
```c
printf("你好，世界！\n");
```

它们做的是同一件事——在屏幕上显示"你好，世界！"，但写法不同。

## 编程语言的分类

### 按"离人类有多近"分

| 类型 | 特点 | 例子 |
|------|------|------|
| 高级语言 | 接近人类语言，容易学 | Python、JavaScript |
| 低级语言 | 接近机器语言，难学但快 | C、汇编语言 |

### 按"怎么翻译"分

| 类型 | 特点 | 例子 |
|------|------|------|
| 解释型 | 边读边执行，像同声传译 | Python、JavaScript |
| 编译型 | 先全部翻译再执行，像翻译一本书 | C、Java、Go |

## 不同语言适合做什么

| 想做的事 | 推荐语言 | 原因 |
|---------|---------|------|
| 刚开始学编程 | Python | 语法最简单，接近英语 |
| 做网站前端 | JavaScript | 浏览器唯一原生支持的语言 |
| 做手机 App | Kotlin / Swift | Android / iOS 官方语言 |
| 做游戏 | C# / C++ | Unity / Unreal 引擎使用 |
| 做人工智能 | Python | 生态最完善，库最多 |
| 做嵌入式/硬件 | C | 运行速度快，资源占用少 |

## 初学者该选哪个

**强烈推荐 Python**，因为：

1. 语法最接近自然语言
2. 不需要写很多"仪式代码"
3. 能做的事情非常多（网站、AI、数据分析、自动化）
4. 学习资源最丰富
5. 就业需求大

## 小测验

1. 编程语言的作用是什么？
   - A. 让计算机更快
   - B. 连接人类和计算机的翻译工具
   - C. 一种外语
   - **答案：B**

2. 初学者最推荐学哪门语言？
   - A. C 语言
   - B. Python
   - C. 汇编语言
   - **答案：B**
