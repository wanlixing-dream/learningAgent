# 计算机是怎么工作的

## 一句话解释

计算机就是一台**超快的计算器**，它能按照你给的指令处理信息。

## 计算机的三个核心部件

用"厨房"来类比：

| 部件 | 类比 | 作用 |
|------|------|------|
| **CPU**（处理器） | 厨师 | 真正干活的，执行所有计算和指令 |
| **内存**（RAM） | 操作台 | 临时放食材的地方，关机就清空 |
| **硬盘**（存储） | 冰箱 | 长期存放东西的地方，关机不丢失 |

### CPU — 厨师

- 速度极快，一秒能执行**几十亿条**指令
- 但一次只能做一件事（现代 CPU 有多个"核心"，相当于多个厨师）
- 只会严格按照指令做事，不会自己发挥

### 内存 — 操作台

- 速度快，但空间有限（通常 8GB~32GB）
- 存放正在使用的程序和数据
- 打开的软件越多，占用越多（就像操作台上东西越多越拥挤）

### 硬盘 — 冰箱

- 空间大（通常 256GB~2TB）
- 速度比内存慢
- 你的文件、照片、软件都存在这里

## 程序运行的过程

```
你双击一个软件
    ↓
硬盘中的程序文件被读取到内存
    ↓
CPU 从内存中逐条读取指令并执行
    ↓
执行结果显示在屏幕上
```

就像：
1. 从冰箱（硬盘）拿出食材
2. 放到操作台（内存）上
3. 厨师（CPU）开始加工
4. 做好的菜端上桌（显示在屏幕）

## 二进制：计算机的"母语"

计算机只认识两个数字：**0 和 1**。

| 你看到的 | 计算机看到的 |
|---------|-----------|
| 字母 A | 01000001 |
| 数字 5 | 00000101 |
| 红色 | 11111111 00000000 00000000 |

所有的文字、图片、视频、音乐，在计算机里都是 0 和 1 的组合。

编程语言的作用就是：让你不需要写 0 和 1，而是用人类能看懂的语言来写指令，然后**自动翻译**成 0 和 1。

## 小测验

1. CPU 在计算机中的角色相当于什么？
   - A. 冰箱
   - B. 操作台
   - C. 厨师
   - **答案：C**

2. 关机后什么会丢失？
   - A. 硬盘里的文件
   - B. 内存里的数据
   - C. 两个都会丢
   - **答案：B**
