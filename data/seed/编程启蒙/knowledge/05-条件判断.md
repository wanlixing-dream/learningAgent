# 条件判断

## 一句话解释

条件判断就是教计算机做选择——**如果满足某个条件，就做 A；否则做 B**。

## 生活类比

你每天出门前的决策：

- **如果**下雨 → 带伞
- **否则如果**太阳很大 → 戴帽子
- **否则** → 直接出门

这就是条件判断！编程里写出来就是：

```python
weather = "下雨"

if weather == "下雨":
    print("带伞")
elif weather == "大太阳":
    print("戴帽子")
else:
    print("直接出门")
```

## 基本语法

### 最简单的 if

```python
age = 18

if age >= 18:
    print("你是成年人")
```

只有 `age >= 18` 成立时，才会执行 `print`。

### if…else（二选一）

```python
score = 55

if score >= 60:
    print("及格了！")
else:
    print("没及格，继续加油")
```

### if…elif…else（多选一）

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")     # ← 这个会执行
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

## 比较运算符

| 符号 | 含义 | 例子 | 结果 |
|------|------|------|------|
| `==` | 等于 | `5 == 5` | True |
| `!=` | 不等于 | `5 != 3` | True |
| `>` | 大于 | `5 > 3` | True |
| `<` | 小于 | `5 < 3` | False |
| `>=` | 大于等于 | `5 >= 5` | True |
| `<=` | 小于等于 | `3 <= 5` | True |

## 组合条件

### 并且（and）

两个条件**都满足**才成立：

```python
age = 20
has_id = True

if age >= 18 and has_id:
    print("可以进入")
```

### 或者（or）

**任一条件**满足就成立：

```python
is_student = True
is_teacher = False

if is_student or is_teacher:
    print("可以使用图书馆")
```

## 小测验

1. `if score >= 60:` 这句代码在做什么？
   - A. 把 score 改成 60
   - B. 判断 score 是否大于等于 60
   - C. 打印 60
   - **答案：B**

2. `and` 的含义是？
   - A. 两个条件都满足才成立
   - B. 任一条件满足就成立
   - C. 取反
   - **答案：A**
