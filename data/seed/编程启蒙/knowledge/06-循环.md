# 循环

## 一句话解释

循环就是让计算机**重复做同一件事**，直到满足某个条件才停下来。

## 生活类比

- 跑步：绕操场跑 **5 圈**（明确次数）
- 吃饭：一直吃**直到吃饱**（不确定次数，看条件）

对应编程里的两种循环：
- `for` 循环 → 跑 5 圈（知道要做几次）
- `while` 循环 → 吃到饱（根据条件决定）

## for 循环：做固定次数

### 打印 5 次"你好"

```python
for i in range(5):
    print("你好")
```

输出：
```
你好
你好
你好
你好
你好
```

### 遍历一个列表

```python
fruits = ["苹果", "香蕉", "橘子"]

for fruit in fruits:
    print(f"我喜欢吃{fruit}")
```

输出：
```
我喜欢吃苹果
我喜欢吃香蕉
我喜欢吃橘子
```

### range() 函数

| 写法 | 产生的数字 |
|------|-----------|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8 |

## while 循环：满足条件就一直做

### 从 1 加到 10

```python
total = 0
number = 1

while number <= 10:
    total = total + number
    number = number + 1

print(total)  # 55
```

### 猜数字游戏

```python
secret = 7
guess = 0

while guess != secret:
    guess = int(input("猜一个数字："))
    if guess < secret:
        print("太小了")
    elif guess > secret:
        print("太大了")

print("恭喜，猜对了！")
```

## 注意：无限循环

```python
# ⚠️ 这段代码会一直运行，永远停不下来！
while True:
    print("停不下来了！")
```

写 while 循环时，一定要确保**条件最终会变成 False**，否则程序会卡死。

## break 和 continue

### break — 立刻跳出循环

```python
for i in range(100):
    if i == 5:
        break       # 到 5 就停
    print(i)
# 输出：0 1 2 3 4
```

### continue — 跳过本次，继续下一次

```python
for i in range(5):
    if i == 2:
        continue    # 跳过 2
    print(i)
# 输出：0 1 3 4
```

   - C. 永远不会停
   - **答案：B**
