# 互联网和网页的基本原理

## 什么是互联网

互联网就是**全世界的计算机通过网线/Wi-Fi 连在一起**，可以互相传递信息。

当你用手机刷视频、发微信、看新闻时，你的设备就在通过互联网和远方的计算机"对话"。

## 网页是怎么到你屏幕上的

```
你在浏览器输入 www.baidu.com
        ↓
浏览器通过互联网找到百度的服务器
        ↓
服务器把网页文件发给你的浏览器
        ↓
浏览器把文件"画"成你看到的网页
```

三个关键角色：

| 角色 | 类比 | 作用 |
|------|------|------|
| **浏览器** | 你的眼睛 | 把代码变成你能看的网页 |
| **服务器** | 图书馆 | 存放网页文件，有人要就发给他 |
| **网络** | 马路 | 连接浏览器和服务器 |

## 网页的三种语言

一个网页由三种语言组成，各管一件事：

| 语言 | 类比 | 管什么 |
|------|------|--------|
| **HTML** | 骨架 | 网页里有什么内容（标题、文字、图片） |
| **CSS** | 衣服 | 内容长什么样（颜色、大小、位置） |
| **JavaScript** | 大脑 | 网页能做什么（点击按钮弹出提示） |

### HTML 示例

```html
<h1>我的第一个网页</h1>
<p>这是一段文字。</p>
<img src="cat.jpg" alt="一只猫">
```

### CSS 示例

```css
h1 {
    color: blue;       /* 标题变蓝色 */
    font-size: 24px;   /* 字体大小 24 像素 */
}
```

### JavaScript 示例

```javascript
// 点击按钮时弹出提示
document.querySelector("button").onclick = function() {
    alert("你点击了按钮！");
};
```

## URL 是什么

URL 就是网页的"地址"，比如：

```
https://www.example.com/about
  ↑         ↑              ↑
协议     域名（网站名字）   路径（具体哪一页）
```

就像快递地址：国家 / 城市 / 街道 / 门牌号。

   - B. HTML
