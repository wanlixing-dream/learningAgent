# HTML 基础

## 什么是 HTML

HTML（HyperText Markup Language）= **超文本标记语言**。

它不是"编程语言"，而是一种"标记语言"——用**标签**告诉浏览器：这是标题、这是段落、这是图片。

## 标签的基本概念

HTML 用 `<标签名>内容</标签名>` 来标记内容：

```html
<h1>这是标题</h1>
<p>这是段落</p>
```

- `<h1>` 是**开始标签**
- `</h1>` 是**结束标签**（多了一个 `/`）
- 两个标签中间的是**内容**

## 最常用的 HTML 标签

| 标签 | 作用 | 例子 |
|------|------|------|
| `<h1>`~`<h6>` | 标题（h1 最大，h6 最小） | `<h1>大标题</h1>` |
| `<p>` | 段落 | `<p>一段文字</p>` |
| `<a>` | 链接 | `<a href="https://baidu.com">百度</a>` |
| `<img>` | 图片 | `<img src="cat.jpg" alt="猫">` |
| `<ul>` + `<li>` | 无序列表 | 见下方 |
| `<ol>` + `<li>` | 有序列表 | 见下方 |
| `<div>` | 容器（用来分组） | `<div>一组内容</div>` |
| `<br>` | 换行 | `第一行<br>第二行` |

### 列表示例

```html
<!-- 无序列表（圆点） -->
<ul>
    <li>苹果</li>
    <li>香蕉</li>
    <li>橘子</li>
</ul>

<!-- 有序列表（数字） -->
<ol>
    <li>起床</li>
    <li>刷牙</li>
    <li>吃早饭</li>
</ol>
```

## 一个完整的 HTML 页面

```html
<!DOCTYPE html>
<html lang="zh">
<head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
</head>
<body>
    <h1>你好，世界！</h1>
    <p>这是我学 HTML 做的第一个网页。</p>
    
    <h2>我喜欢的水果</h2>
    <ul>
        <li>苹果</li>
        <li>香蕉</li>
    </ul>
    
    <p>点击这里去 <a href="https://www.baidu.com">百度</a></p>
</body>
</html>
```

### 页面结构说明

```
<!DOCTYPE html>      ← 告诉浏览器这是 HTML5
<html>               ← 整个页面的根
  <head>             ← 页面的"元信息"（标题、编码等）
  </head>
  <body>             ← 页面的"正文"（用户看到的内容）
  </body>
</html>
```

## 小测验

1. HTML 中 `<p>` 标签表示什么？
   - A. 图片
   - B. 段落
   - C. 链接
   - **答案：B**

2. 每个 HTML 页面的可见内容写在哪个标签里？
   - A. `<head>`
   - B. `<body>`
   - C. `<title>`
   - **答案：B**
