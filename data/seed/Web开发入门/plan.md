# Web 开发入门 — 学习计划

> 适合人群：想了解网站是怎么做出来的初学者

## 学习目标

理解网页的基本组成（HTML + CSS + JavaScript），能做出一个简单的个人主页。

## 学习路径

### 第一阶段：网页是什么（第 1 周）

1. **互联网和网页的基本原理** — 浏览器、服务器、URL
2. **HTML 基础** — 网页的"骨架"
3. **CSS 基础** — 网页的"衣服"

### 第二阶段：让网页动起来（第 2 周）

4. **JavaScript 基础** — 网页的"大脑"
5. **DOM 操作** — 用代码改变网页内容

### 第三阶段：实战（第 3 周）

6. **项目：个人主页** — 综合 HTML + CSS
7. **前端和后端** — 完整网站的全貌
8. **下一步学什么** — React/Vue、Node.js、数据库

## 评估方式

- 能独立写出包含标题、图片、链接的 HTML 页面
- 能用 CSS 修改颜色、字体、布局
